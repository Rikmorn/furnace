**Epic 2 · Slice 2.2.2 ("Theme-Generator Architecture") then landed (2026-06-24):** the three hardcoded single-kind cave configs were replaced by a pluggable, pure, deterministic theme-generator architecture. `packages/dungeon/src/region.ts` defines the `RegionData` contract (meshes + colliders + materials + `Connection`s + provenance) and a `themes` registry of pure `(RegionParams) → RegionData` generators; `realize.ts` (`realizeRegion` + `MaterialCache`) turns that data into GPU meshes + static colliders into a world (one shared material per distinct descriptor); `compose.ts` (`buildArea`) assembles a branching cave + a per-branch vestibule + a room via cardinal-snap placement (yaw-mapped door→mouth join). Three themes: a branching SDF `cave` (`themes/cave.ts` — a hub + floor-routed capsule tunnels via new `field.ts` primitives `capsuleCavern`/`smoothUnion`/`yTaperedNoiseDisplace`, meshed by Surface-Nets and collided by a field-derived voxel proxy) and box-architecture `pillarHall`/`greatHall` (a shared `themes/box-room.ts` builder → cuboid walls/doorway/pillars/dais+steps with `cuboid` colliders). The flat-floored vestibule (`compose.ts`) bridges each cave mouth to a room door so the cave voxels only ever overlap a coplanar cuboid floor — the proven 2.2.1 seam geometry. The single-kind `generator.ts` (the retired shaft/chamber kinds + the `Pass`/`RegionModel` scaffolding) was deleted; its surviving baked-cavern path is preserved byte-for-byte as `bakedCavernProxy` in `themes/cave.ts` (the cavern still renders from its `.fmesh` and collides against this runtime-regenerated voxel proxy). No `@furnace/core` change. Headless: `region.ts`/`compose.ts` placement math is unit-tested, `bakedCavernProxy` determinism is unit-tested (`tests/cavern-proxy.test.ts`), and the composed walk (`area-traversal.gpu.test.ts` — cave→vestibule→room, plus the greatHall dais climb) and the re-pointed full-world fuzz harness (`traversal.gpu.test.ts` — cave-hub lanes, the level↔wing seam walk, and a no-fall-through floor-ray grid over the authored 2nd chamber) are `.gpu.test.ts`-covered; theme/composition feel stays a visual gate.
