**Epic 2 · Slice 2.1 ("Field→Baked Region") then landed:** the clean break from box-AABB geometry. Core gained: `@furnace/core/rng` (seeded sfc32 PRNG with `float/int/bool/pick/derive`); physics `trimesh` collider variant (`ShapeDescriptor`); `geometry.create` `{ retainForCollision }` opt + `geometry.getCollisionData`; scene `"mesh"` geometry resource (fetches + decodes a `.fmesh`); `rigidBody.shape.trimesh: true` (boolean flag → pulls collision arrays from the sibling geometry); `settings.region` metadata block (`{ provenance?, theme?, origin? }`); `loadScene` `world`-injection + `fragment` mode (`LoadSceneOptions`); and the `encodeMeshBlob`/`decodeMeshBlob` `.fmesh` codec. The dungeon adds a density-field pipeline (`f(seed, pos) → density`) run through a naive Surface Nets mesher that produces three procedurally generated rooms on the authored hand-carved spine: a **cavern grotto** (a descent-into bowl), a **vertical shaft** (a drop), and a **walk-in bumpy chamber floor**. The chamber floor region is baked to a `.fmesh` sidecar file + a region scene document by a throwaway one-shot baker script, then loaded back via `loadScene({ world, fragment: true })` into the live game world — exercising the full persistence round-trip. The real Rapier trimesh collider replaces the box-AABB approach for the generated geometry. Chamber floor visual polish (seams, visibility tuning) is deferred to `docs/backlog/dungeon/chamber-floor-seams-and-visibility.md`. Headless: the core rng, physics trimesh surface + scene round-trip are `.gpu.test.ts`-covered (or unit-tested for pure math); the dungeon's pure math (`gravityStep`/`moveDelta`/`forwardVector`) and the `.fmesh` codec are unit-tested; generated room feel is gated visually (Safari/Chrome), not by the suite.
