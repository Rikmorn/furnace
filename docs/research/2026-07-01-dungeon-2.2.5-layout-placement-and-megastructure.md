# World-graph layout, collision-aware placement, and the megastructure north star — research for Slice 2.2.5

> **Status:** Pre-decision research feeding the Slice 2.2.5 ("Layout — the world graph")
> scope, produced 2026-07-01 by a 4-agent cited prior-art pass (megastructure generation ·
> vertical 3D level generation · graph world-models for hierarchy/theming/streaming · layout
> algorithm comparison). It grounded the 2.2.5a placement-algorithm decision — **overturning
> the force-directed-relaxation candidate** in favour of a deterministic incremental
> graph-embedding placer (the Ma/Edgar shape) — and recorded the megastructure-scale
> requirements (verticality-as-edge-data, hierarchy-as-decomposition, boundary pinning) that
> the world-graph contract bakes in early. The as-built design lives in `AGENTS.md` + source
> on landing.

**Epistemic key:** `[V]` verified from a cited source · `[K]` established general knowledge ·
`[I]` inference about fit to our pipeline.

Grounded in the dungeon's actual pipeline (verified this session): heterogeneous regions
(SDF caves / box rooms) declaring `Connection` portals, joined by the 2.2.4 primitive —
`connect.ts join` (continuous yaw + height portal mating) and `route` (corridor/ramp/stairs
connectors, walkable by construction via the shared `walkability.ts` constants). Composition
is still hand-written (`compose.ts`), and the 2.2.4 gate showed the missing piece is
**collision-aware placement** (the showcase interpenetrated/floated). The user's stated
north star: a **megastructure generator** — vast artificial structures with huge vertical
shafts, platforms, fully-vertical play, themed sub-areas, streaming, macro/micro passes
hung off a graph.

## 1. Megastructure prior art — nobody macro-generates one, but the generative pattern is uniform

- **[V]** The canonical megastructure games are AUTHORED: NaissanceE is "thousands upon
  thousands of crate-sized cubes" elevated by lighting/animation craft (Robert Yang); Echo's
  planet-sized palace is a hand-assembled modular kit with vastness by vista + fiction;
  Manifold Garden's infinity is literal instancing (n³ decimated world copies, SIGGRAPH 2020).
- **[V]** Every successful *generative* large-layout system shares one architecture: **an
  explicit macro pass owns global structure; local-texture algorithms are strictly
  subordinate.** Caves of Qud's raw-WFC failures (homogeneity/overfitting/connectivity) were
  fixed by a coarse architectural pass WFC fills inside; Unexplored's grammar operates on a
  higher-order cycle structure; Cogmind hand-authors the world graph over parameterized map
  generators; Minecraft's jigsaw anchors large structures on an authored centre-piece then
  grows outward.
- **[V/I]** Feel levers for "one vast artifact": superstructural skeleton as first-class;
  nested coarse→fine passes (CGA mass-model → facade → ornament); repetition-with-variation
  over a *tiny* archetype kit (NaissanceE's one cube — archetype poverty is not a blocker);
  cycles/locks for intentionality (a tree-shaped world is the known "random scatter" failure
  mode); controlled illegibility as a cheap theme parameter (BLAME!); distant-vista imagery is
  separable from walkable structure (demoscene greeble/KIFS — pure rendering, not layout).
- **[V]** Hahn et al. 2006 (*Persistent Realtime Building Interior Generation*) is direct
  precedent for our streaming posture: building interiors generated only when entered, from
  seeds, regenerating identically — "bounded region realized on demand, deterministic" was
  proven viable in 2006.

## 2. Verticality — edge data, not node data

- **[V]** VAZGRIZ's 3D dungeon realizes a vertical transition as an **atomic multi-cell A\***
  **move** — fixed rise:run 1:2, occupied cells + **two reserved headroom cells above the
  stair** + mandatory landings at both ends. Verticality is a fat, constraint-checked move in
  the *connector router's* action set, with a volumetric footprint.
- **[V]** Spelunky's verticality is a **typed room-pair contract** (bottom-exit room stacked
  on top-exit room along a never-upward solution path); Dead Cells authors verticality into a
  per-biome node graph filled from exit-compatible templates.
- **[V]** One-way (fall) edges have a standard model: edges carry a traversal predicate that
  may be asymmetric (`canTraverse(edge, direction, verbSet)`); validity = **monotone
  reachability closure** (Stalnaker's metroidvania thesis — expand the reachable set through
  satisfiable gates to a fixed point); the pleasant discipline is a walk-only guaranteed spine
  with drops as shortcuts (Spelunky). Engine-grade sibling: Unity/Recast auto-generated
  **one-directional** drop-down nav links parameterized by agent move-set scalars.
- **[V/I]** Deep Rock Galactic is the anti-pattern for us: it never proves traversability —
  the verb set (drills, platform gun, ziplines) rescues any topology. With walk-only verbs we
  must stay walkable-by-construction (our `route` posture), and **headroom is the recurring
  forgotten constraint** (VAZGRIZ is the only surveyed system modelling it explicitly; our
  own `charmover-stepup-into-low-ceiling-guard.md` backlog is this bug already observed).
- **[I]** Contract consequence: world-graph edges should carry
  `{heightDelta, directed?, requiredVerbs}` from day one (all symmetric/walk-only today);
  nodes stay orientation-agnostic; the router owns vertical semantics.

## 3. Hierarchy, theming, streaming — every shipped embedding is local

- **[V]** **No shipped system surveyed embeds a world graph by global force-directed
  relaxation.** The four strategies in use: (1) grammar rewriting constrained to a spatial
  substrate so the graph is never un-embedded (Unexplored's 5×5 node grid; U2's 80-cell
  Voronoi); (2) **incremental placement with typed portals + overlap testing + backtracking**
  (Warframe's depth-first block assembly with rollback — published pseudocode; portal-socket
  compatibility + no-overlap test per placement; caps close unused portals); (3)
  **plan-at-anchor + lazy per-chunk materialization** (Minecraft `structure_starts` /
  `structure_references` — one deterministic owner computes the whole multi-chunk plan,
  neighbours dereference it); (4) fixed-boundary constraint solving with bounded dependency
  DAGs (marian42's infinite WFC — per-chunk solve inside deterministic boundary constraints;
  BorisTheBrave's "Infinite Modifying in Blocks" — constant fan-in, lazy, deterministic).
- **[V]** "Graph of graphs" is shipped, twice, in directly relevant forms: Unexplored 2
  (macro region graph → per-node area generator producing its own annotated internal graph)
  and Warframe (block adjacency graph → per-block authored TacMaps stitched at portals into
  one whole-level graph).
- **[V]** **"Pin the interface, solve the interior" is named prior art**: marian42's boundary
  constraints, Merrell's modifying-in-blocks (frozen overlap tiles), Spelunky's exit-obligated
  room templates, Warframe's small closed portal-type vocabulary. Generating a child region
  given parent-pinned portals is the established composition seam — i.e. our pinned-node
  mechanism *is* the hierarchy/streaming seam, unchanged.
- **[V]** Theming over a graph: annotations on nodes/subgraphs gate which local
  generators/rules may fire (Unexplored's biome/fire cascade; Warframe's restricted block
  pools); difficulty derives from graph distance (U2's distance-to-start/goal); theme
  transitions are placed ON connector seams so they read as physical boundaries (U2's
  barrier-on-border).

## 4. Layout algorithm comparison — the decision

- **[V]** **TinyKeep is not a precedent for graph-first force layout.** It scattered rooms,
  physically separated them, then *derived* the graph (Delaunay→MST→loops) from wherever
  rooms ended up — the inverse of our problem. No shipped game was found using force-directed
  layout of an *authored* graph.
- **[V]** Force-directed verdict: local minima ("basic force-directed algorithms are not able
  to consistently produce good layouts for large graphs" — Kobourov, GD Handbook), no
  convergence guarantee, hard no-overlap is emergent not invariant, global coupling fights
  streaming, and physics separation destroys planned portal adjacency. **Disqualified as the
  correctness mechanism**; at most a fixed-iteration aesthetic pass whose output is
  re-validated.
- **[V]** The dominant shipped family is **incremental growth + collision rejection +
  backtracking**: Warframe (DFS with rollback), DunGen (Unity; ships Lethal Company —
  overlap-threshold / padding / vertical-overhang controls), Dungeon Architect (flow graph
  grown on a 3D occupancy grid). Hard no-overlap **by construction**; best locality
  (frontier-based = streamable). Its verified anti-pattern: DunGen's standalone builds "keep
  retrying indefinitely until it succeeds" — retry-forever, the opposite of our setup-loud
  posture; we invert it (bounded backtracking budget → throw with diagnostics).
- **[V]** The bullseye academic hybrid: **Ma, Vining, Lefebvre, Sheffer — "Game Level Layout
  from Design Specification" (Eurographics 2014)** and its maintained production
  implementation **Edgar** (Nepožitek). Input = an *authored* connectivity graph + room
  shapes (our exact problem, in 2D): chain decomposition with **cycles laid out first** and
  pins frozen, incremental chain-by-chain placement from precomputed configuration spaces,
  **stack-based backtracking across chains**, hard no-overlap, "complex layouts in seconds."
- **[I]** Our 2.2.4 connectors *relax* Edgar's hardest constraint: it fights for contact-based
  adjacency; our connectors are straight and arbitrary-length, so **closing a cycle edge
  degrades to a check** (does a collision-free walkable route exist between two placed
  portals), not a search.
- **[V/I]** Constraint solving (ASP/SAT/WFC) offers the strongest guarantees (UNSAT is
  provable = native fail-loud) but requires discretizing our continuous yaw/height frames and
  carries exponential cliffs near phase transitions — kept as a possible per-sector upgrade,
  not the base. Grid+A\* (VAZGRIZ) re-imposes the axis-aligned quantization 2.2.4 was built
  to escape — its occupancy grid survives as broad-phase inspiration and its A\* as a future
  *connector-router* upgrade, not the placement domain.
- **[V/I]** Hierarchy for scale should be **decomposition, not multilevel refinement**: a
  coarse sector graph (envelope AABB + boundary portals per sector) placed by the same
  algorithm, then sector interiors generated independently and lazily inside their envelopes
  with frozen boundary portals (the marian42/N-WFC/Minecraft pattern). Multilevel
  graph-drawing refinement has no game-placement precedent and adds no guarantee.

## Net assessment

- **The graph instinct is the validated pattern.** Every successful large-scale generative
  system gives global structure to an explicit macro pass. A topology graph is not the
  "mechanical" thing the north star rejected (that was discrete-platter *realization*).
- **Force-directed relaxation is overturned** as the placement foundation — not for ambition
  reasons but on evidence: no graph-first precedent, weak guarantees, anti-streaming,
  adjacency-destroying. The genuinely powerful choice on the megastructure axes (locality,
  hierarchy, hard guarantees, planned cycles) is the **Edgar-shaped deterministic incremental
  embedding**: pins frozen → most-constrained-first order → candidates by portal-mating
  (`join`) at seeded lengths/yaws → hard accept (no envelope overlap + connector clearance
  volumes + closing-edge realizability) → bounded backtracking → throw setup-loud.
- **Cheap-now, expensive-later contract items** the megastructure lens promotes: edges carry
  `{heightDelta, directed?, requiredVerbs}`; nodes carry theme annotations + envelope AABBs;
  connector placement tests a *clearance volume* (headroom), not just a floor slab; pinned
  nodes double as the hierarchy/streaming seam.

## Decisions this fed (Slice 2.2.5)

- **2.2.5 split (user, 2026-07-01): foundation-first sub-ladder.** 2.2.5a = world-graph
  contract + the Edgar-shaped collision-aware placer + `route` hardening (descending-stairs
  fix, headroom-as-clearance), proven by re-composing the EXISTING dungeon from a hand-written
  graph (authored chamber as a pinned landmark; vertical edges; one loop; rough 2.2.4
  showcase redone correctly and its hand-tuning deleted). 2.2.5b = the graph *generator*
  (themed, cyclic-capable topology) delivering per-seed variety.
- Force-directed relaxation demoted to an optional future aesthetic pass (fixed-iteration,
  re-validated); not built in 2.2.5a.
- Sector hierarchy + streaming documented as the decomposition seam (pinned boundary
  portals), deliberately not built until the megastructure epic needs it.
