# Vocabulary expansion

Cycle 2's finding, stated plainly: **material is what makes a place a place.** A 2.4× width
contrast read as "rooms"; a different material read as a distinct place. The content
vocabulary is therefore the differentiation ceiling — not the generator, not the brush.

**The target shape:** roughly a class per distinct place the world wants to have. That is
the cycle-2 ceiling restated as a requirement.

**Rides along:** the scatter-variants hazard
(`docs/backlog/engine-architecture/scatter-variants-not-bound-to-archetype.md`) — variants
are not bound to their archetype, which bites harder the moment the vocabulary grows.

**It fires the skill word-pin re-review.** The agent world-building skill's word pin is a
*drift alarm*, not a budget: expanding the vocabulary is exactly the kind of change that
should make it fire, and the binding response is re-review and re-ratification, never a
silent bump. See `docs/reference/docs-system.md` §7.

**Annotate that pin while you have it open.** It does not yet state its kind or its binding
response in the test — it is named `WORD_BUDGET`, which reads as the wrong kind. This slice
is its ruled carrier; add the annotation per §7 when the re-review fires.
