# Mirror / symmetry

*(Adjudicated in the F4.5 charter's §7 capability sweep, 2026-07-29 — one sitting, every capability of the category weighed against the others; the stage that produced the sweep is sealed at `docs/learnings/seals/2026-08-03-epic3-f4.5-overlay-cockpit.md`.)*

No symmetry plane; every edit is what the brush touches. This is a substantial feature (a
plane, a mirrored op for every op kind, and a decision about what mirroring does to placements
and to committed generator entities), and it is the kind of thing that has to be designed into
the op log rather than added over it.

**Trigger to revisit:** authoring something whose symmetry is load-bearing — a built structure rather
than a cave. Decide it as a design question, not as a feature request.

**Reference:** the op log, which is what a symmetry plane has to be designed into rather than layered over; `docs/reference/editor/chrome.md`, `design-system.md` and `tools.md` for everything the same sweep put in the adopt column.
