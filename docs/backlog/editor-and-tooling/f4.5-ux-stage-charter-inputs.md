- **Menus** (incl. items locked/irrelevant in context — the scene menu in a field
  session).
- **Panels** and **wasted real estate**.
- **Deprecated features whose UI affordances remain** — "loads of" dead controls. A
  named instance already on record: the seed input + re-roll rendered unconditionally
  for generators that ignore seed (hall). Wants a sweep: every control either does
  something or does not exist.

  have a huge form with limited number values"; bounded values want dials/sliders.
- **Form validation errors render at the BOTTOM of long forms**, forcing a scroll to
  discover why the commit refused — the error affordance belongs at/near the field,
  or pinned visible.
