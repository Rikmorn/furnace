# @furnace/cookbook

The reference cookbook: one page per Tier 1 engine feature, as a browseable demo collection.

## Role

Co-evolves with `docs/reference/core-modules.md`: **the cookbook shows it, core-modules documents it.** A consumer-visible `@furnace/core` API change lands with the matching cookbook demo in the same PR (see AGENTS.md §"Keeping docs current").

Demo posture (deliberately INVERTED from engine/scaffold minimalism): the question is "what does this teach?" — enrich a demo until the lesson is visible.
